
# My Computing Journey

## Project Overview

This website was created for my Web Development II module at Bath Spa University. It shares my computing journey, developing technical skills and experiences travelling to South Korea and Japan.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive Read More button
- Visual Studio Code – Code editor

## Reflection

I created this website to practise HTML, CSS and JavaScript while sharing my personal computing journey.

I used HTML to organise the content into sections, CSS Grid to display my computing skills and Flexbox to position my travel photographs beside their descriptions.

One challenge I faced was adjusting the size of my photographs and the website's header image. I learned how important it is for HTML section IDs and CSS selectors to match.

I also gained more confidence using Visual Studio Code, organising project files and testing changes in the browser.

This project helped me understand how HTML, CSS and JavaScript work together. As I continue studying Computing, I would like to improve my website's mobile layout and develop more interactive features.
